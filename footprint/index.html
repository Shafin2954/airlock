Get your Claude export

  1. Settings → Privacy → Export data
  2. A download link arrives by email
  3. Drop the downloaded .zip here

Menu names change from time to time; look for "export data" in each app's settings. This page has no server and is blocked from making network requests (Content-Security-Policy connect-src 'none'), so your export stays on your device. You can also save this page and run it offline.
